# felipe-ad-creative-matrix

Output lives in `~/niche-ad-pages/<slug>/`. HTML is generated by `scripts/build.py`, never hand-edited. Checks run in `scripts/check.py`.

## Fixed constants (never re-ask)

- **CTA:** `DM me SCALE to learn how` (one CTA, always, the writer never writes it)
- **Offer:** `$50K to $250K from the bank at 0% interest` (credit stacking). Always these numbers.
- **Audience:** in-market buyers: already know they want capital, deciding who to go with (~700+ FICO).
- **Page title:** the business name. Unguessable public URL is fine.
- **Proof I can claim:** NONE (unless the user supplies proof for a run).

## 1. Interview

1. **Business name** (first question, always).
2. **3 to 5 niches.**
3. **Avatar brief per niche, 3 questions.** Draft answers from any notes you have on the niche, show them as DRAFT with source, and ask the user to confirm or correct in one batch:
   - Typical revenue and crew size
   - How they fund equipment today, and what friction they hit
   - What puts this owner in-market right now (the trigger)
   Anything the user can't answer stays `UNKNOWN`. Never fill it with a guess.

## 2. One writer per niche, in parallel

Spawn one fresh Claude subagent per niche (Agent tool, run in the background) and send it the filled prompt. Fix-it rewrites go back to THAT niche's agent via SendMessage so it sees its own draft. Never reuse one niche's agent for another.

The agent is fresh, so the prompt carries all context. The base prompt is `scripts/prompt.template.txt` (XML-structured, already Lyra-optimized 2026-10-13). Placeholders: `[NICHE]`, `[AVATAR_BRIEF]`.

### 2a. Lyra pass (optional, needs the `lyra` skill; skip to use the template as is)

1. Invoke `Skill lyra` with args: `BASIC mode. Optimize the prompt in ~/.claude/skills/felipe-ad-creative-matrix/scripts/prompt.template.txt for a Claude writer. Keep the [NICHE] and [AVATAR_BRIEF] placeholders, the XML structure, the offer, the fixed CTA text, the compliance list, the two-beat hook rule, and the "NEITHER body contains a CTA" line word for word. You may tighten wording, remove duplication, and improve ordering.`
2. Save Lyra's optimized prompt (the prompt only, no commentary) to `~/niche-ad-pages/<slug>/prompt.lyra.txt`. Then leave Lyra mode.
3. Guard: `python3 ~/.claude/skills/felipe-ad-creative-matrix/scripts/fill_prompt.py ~/niche-ad-pages/<slug>/prompt.lyra.txt "<niche>" <niche>.brief.txt > <niche>.prompt.txt`. If it prints `GUARD FAIL`, Lyra dropped a constraint: use `scripts/prompt.template.txt` instead and tell the user once.
4. Send the contents of `<niche>.prompt.txt` as the prompt to that niche's writer agent.

If Lyra returns the prompt essentially unchanged, say so in one line and move on.

## 3. Check pass

1. Save the writer's JSON to `~/niche-ad-pages/<slug>/<niche>.json` and the brief to `<niche>.brief.txt`.
2. `python3 ~/.claude/skills/felipe-ad-creative-matrix/scripts/check.py <niche>.json <niche>.brief.txt` handles the deterministic checks: counts, hook word count, no question marks, two-beat shape, at most 3 avatar-label openers, unique first 3 words, numbers not in brief or offer, banned words (guarantee, approved, "everyone", personal guarantee, collateral, months, years, em dashes), body word range, proof-pattern phrases ("owners are", "operators are", "clients").
3. Claude reads what the script can't judge: each body has a real reframe, each body works after any hook, hooks are niche-only, the two bodies are different pockets.
4. Failed items only go back to THAT niche's writer agent, listing the exact failures.

## 3b. Slop pass (optional, needs the `no-ai-slop` skill; automatic, no ask)

Runs per niche once step 3 is clean, before Build. Edits apply on their own. The user sees the result in the report, never an approval prompt.

1. Keep the clean copy: `cp <niche>.json <niche>.preslop.json`.
2. Invoke `Skill no-ai-slop` in EDIT mode on the 10 hooks and 2 bodies of that niche. Run all niches in one pass when there are several. Pass these constraints with the copy:
   - It is spoken video script. Fragments and spoken rhythm stay. Voice to preserve = direct-response delivery.
   - Do not touch the offer numbers (`$50K to $250K`, `0% interest`), the niche circumstance in each hook, or the reframe in each body.
   - If a reframe is written as a binary contrast ("That isn't X. It's Y."), restate it as one plain sentence that keeps the blame on the missing process or knowledge. Never delete it.
   - Hooks stay 10 words or fewer, a statement, two beats split by a comma or period, unique first 3 words.
   - Bodies stay 60 to 80 words and contain no CTA.
   - Add no claims, numbers, scenes, proof, or timeline. No em dashes.
   - Common hits to expect: faux-insight setups ("Here's what nobody tells you"), binary contrasts ("That's not X. That's Y."), "It's a process, not a privilege" kickers, throat-clearing, negative listing.
3. Save the edited JSON (same shape) as `<niche>.slop.json`.
4. Apply with the guard: `python3 ~/.claude/skills/felipe-ad-creative-matrix/scripts/slop_merge.py <niche>.preslop.json <niche>.slop.json <niche>.brief.txt > <niche>.json`. It keeps each edit only if `check.py` still passes with it swapped in, and reverts any edit that breaks a hard rule (stderr shows KEEP / REVERT per item).
5. Claude reads the merged copy once for what the script can't see: each reframe survived, each body still works after any hook, no meaning drifted, the cadence still sounds spoken. Fix any drift by hand, then rerun `check.py`.
   - A REVERT on a body for word count (under 60 or over 80) means the slop edit was right but the length slipped. Do not accept the revert. Take the edited body from `<niche>.slop.json`, adjust the length by hand (add or cut one concrete line, never a kicker), and rerun `check.py`. Only keep the original if the edit itself broke a hard rule other than length.
6. Report in one line per niche: items edited, items reverted, anything that drifted.

After any later fix-it round, rerun steps 1 to 6 on the final copy before Build.

## 4. Build

1. `niches.json` in `~/niche-ad-pages/<slug>/`:
   ```json
   {"business":"<name>","offer":"$50K to $250K from the bank at 0% interest","cta":"DM me SCALE to learn how",
    "niches":[{"name":"Land Clearing","hooks":[...10],"bodies":[...2]}]}
   ```
2. `python3 ~/.claude/skills/felipe-ad-creative-matrix/scripts/build.py ~/niche-ad-pages/<slug>` (asserts counts).
3. Preview: `open ~/niche-ad-pages/<slug>/index.html`.

## 5. Deploy (Cloudflare Pages, never Netlify)

```
P=<slug>-$(openssl rand -hex 4)
npx wrangler pages project create "$P" --production-branch main
npx wrangler pages deploy ~/niche-ad-pages/<slug> --project-name "$P" --branch main
```

Return ONE URL: `https://$P.pages.dev`. Page ships `noindex`. Save `$P` in `<slug>/.project`. Adding a niche later: edit `niches.json`, rebuild, redeploy to the same project.

## Gotchas

- The writer invents claims and scenes. Check every one before anything goes live.
- 48-hour rule: one niche live today, add the rest after.
